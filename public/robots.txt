# Content Signals (contentsignals.org / IETF draft)
# ai-train=no    — do not use M3X content to train foundation models
# search=yes     — allow indexing for AI-powered search / retrieval
# ai-input=yes   — allow agents to use this content as context input
Content-Signal: ai-train=no, search=yes, ai-input=yes
#
# Strategy:
#   - Training crawlers (GPTBot, ClaudeBot, CCBot, etc.) → disallow everywhere
#   - Search/retrieval crawlers (OAI-SearchBot, Claude-SearchBot, Perplexity) → allow public content
#   - Standard search engines → allow public content
#   - All bots → block authenticated user surfaces (dashboard, inbox, intents)
#   - All bots → can always read AI discovery files (llms.txt, .well-known/, openapi)
